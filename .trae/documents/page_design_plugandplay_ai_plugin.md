# 即插即用插件 - 页面设计规范（桌面优先）

## 全局设计（Global Styles）
- 设计基调：工具型面板，信息密度中等，减少视觉干扰。
- 颜色 Token（示例，可按宿主主题映射）：
  - `--bg`: #0B1220（深色背景）/ #FFFFFF（浅色）
  - `--panel`: #111A2E / #F7F8FA
  - `--text`: #E6EAF2 / #0F172A
  - `--muted`: #9AA4B2 / #64748B
  - `--primary`: #4F46E5
  - `--danger`: #EF4444
- 字体与排版：
  - 字体：系统字体栈（宿主优先）
  - 标题：16–18px semibold；正文：13–14px regular；辅助：12px
- 组件状态：
  - Button：默认/hover 提升亮度；disabled 降低不透明度；loading 显示 spinner
  - Input：focus 以 primary 描边；错误态以 danger 提示
- 响应式：桌面优先（推荐面板宽 360–480px）；小于 360px 时收起部分标签为 icon + tooltip。

## Page 1：插件工作台（/）

### Meta Information
- Title: 即插即用AI插件工作台
- Description: 豆包文生图与腾讯混元3D图生3D一体化面板
- Open Graph: 与宿主共享或禁用（插件内嵌场景通常不需要传播）

### Layout
- 布局系统：Flexbox + 局部 Grid
- 顶部工具栏固定（sticky）；内容区可滚动；预览区根据面板宽度自适应。

### Page Structure
- 上下分区：
  1) 顶部栏（能力切换 + 状态）
  2) 主操作区（表单 + 操作按钮）
  3) 结果区（2D 图片网格 / 3D 预览卡片）

### Sections & Components
1. 顶部栏（Header / Toolbar）
   - 左侧：产品名/图标（可选）
   - 中部：Tab 切换
     - Tab A：文生图（豆包）
     - Tab B：图生3D（腾讯混元3D）
   - 右侧：
     - “设置”按钮（跳转 /settings）
     - 全局状态 Badge：空闲/生成中/失败

2. 文生图面板（Tab：文生图）
   - Prompt 输入区：
     - 多行 Textarea（支持粘贴）
     - 字数提示（可选，仅提示不强制）
   - 参数区（最小化）：
     - Size 下拉（如 512/768/1024，具体由后端映射）
     - 张数 n（Stepper）
   - 操作：
     - 主按钮“生成图片”
     - 生成中禁用输入，显示进度与取消（如后端支持则启用）

3. 图片结果区（文生图输出）
   - Grid：2 列（面板窄）/ 3 列（面板宽）
   - 卡片内容：缩略图 + “用于图生3D”按钮
   - 点击缩略图：打开轻量预览（Modal）

4. 图生3D面板（Tab：图生3D）
   - 输入图片区：
     - 显示当前选中图片（来自上一步或宿主注入）
     - “更换图片”入口（返回图片列表选择）
   - 操作：
     - 主按钮“生成3D”
     - 任务状态条：queued/running/succeeded/failed

5. 3D 结果预览区
   - 使用 3D Viewer 容器（建议 16:9 或 1:1，自适应高度）
   - 基础交互：旋转/缩放（鼠标拖拽/滚轮）
   - 成功态：展示模型
   - 失败态：展示错误信息与“重试”按钮

6. 与宿主通信提示（可折叠）
   - 显示“结果已回传到宿主/可在宿主画布中插入”等状态（由嵌入方案决定）

## Page 2：设置与授权（/settings）

### Meta Information
- Title: 设置与授权
- Description: 配置豆包与混元3D调用方式及连通性校验

### Layout
- 布局系统：单列表单（Flex column），分组 Card
- 顶部返回按钮固定，表单可滚动。

### Page Structure
- 分组：
  1) 调用方式
  2) 连通性校验
  3) 调试信息（可选，默认折叠）

### Sections & Components
1. 调用方式（Card）
   - 选项：
     - “由插件后端托管密钥（推荐）”
     - “由宿主注入短期 Token（企业集成）”
   - 根据选择展示字段（最小必要）：
     - 若后端托管：仅提示“密钥在服务端配置，不在此处填写”
     - 若宿主注入：输入 Token（短期）或显示当前注入状态

2. 连通性校验（Card）
   - 两个独立测试项：
     - 测试豆包文生图
     - 测试混元3D图生3D
   - 展示结果：成功/失败 + 错误信息（可复制）

3. 调试信息（折叠面板）
   - 显示：API Base URL、版本号、最近一次请求时间（仅展示，不额外采集）

## 交互与动效建议（轻量）
- Tab 切换：200ms 淡入淡出
- 生成中：按钮内 spinner + 状态条
- 错误提示：在表单下方 inline 展示，必要时 Toast 提示
