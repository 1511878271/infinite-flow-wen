# AI “文生图 & 图生3D” 插件功能使用说明
运行程序：npm run dev
一般情况的运行网址：http://localhost:5173/

欢迎使用这款即插即用的 AI 社交与内容生成插件！
本插件不仅提供强大的 AI 图像和 3D 模型生成能力，还内置聊天Demo。

---

## 1. 核心生成功能

### 1.1 文生图 (Text-to-Image)
通过文字描述，快速生成高质量的 2D 图像（基于火山引擎/豆包大模型）。

- **操作步骤：**
  1. 在顶部标签页切换到 **“文生图”**。
  2. 在**提示词**框中输入你想要的画面描述（例如：“生成一只可爱的小猪图片”）。
  3. 选择生成的**尺寸**（如：1K, 2K）以及需要生成的**张数**（最多 4 张）。
  4. 点击 **“生成图片”**。
- **图片操作：**
  - **用于图生3D**：点击单张图片下方的按钮，可直接将该图片发送到“图生3D”面板。
  - **上传COS**：将图片上传至云端对象存储（可选）。
  - **原图**：查看高清原图。

### 1.2 图生3D (Image-to-3D)
将 2D 图像一键转换为全视角的 3D 模型（`.glb` 格式，基于腾讯混元 3D 大模型）。

- **操作步骤：**
  1. 在顶部标签页切换到 **“图生3D”**。
  2. **选择图片来源**：
     - 可以从“文生图”直接发送过来。
     - 或者点击 **“上传本地图片”** / **“更换图片”**，从你的电脑中选择本地图片。
  3. 确认图片后，点击 **“生成 3D 模型”**。
- **注意：** 3D 模型生成通常需要几分钟时间，请耐心等待。生成成功后，你可以在面板中直接拖拽鼠标 360° 预览 3D 模型。

## 2. 沉浸式互动体

这是一个突破传统的 3D 社交聊天 Demo，允许你使用生成的 3D 模型作为全息化身，并用“情绪”进行交流。

- **进入方式：** 在普通插件面板的顶部导航栏，点击 **“共鸣场 Demo”**。
- **功能玩法：**
  1. **设置 3D 化身：** 
     - 将鼠标悬停在左侧（对方）或右侧（自己）的化身上，底部会浮现 **“更换化身”** 按钮。
     - 点击后可从“历史生成的模型/图片”中选择，或直接 **上传本地 `.glb` 模型**。
     - 鼠标左键按住化身可以自由旋转视角。
  2. **发送情绪消息：**
     - 在底部控制台的**情绪轮盘**中选择一种情绪（开心、愤怒、难过、嘲讽、平静）。
     - 输入你想说的话并点击发送（或按 Enter）。
     - 舞台背景光效、化身的物理动画（震动、靠近等）以及全息文字弹幕，会根据你选择的情绪发生戏剧性变化！
  3. **自定义全息动态背景：**
     - 点击右上角的 **“更换背景视频”**，你可以上传本地生成的动态视频（`.mp4`, `.webm`），它会以半透明全息质感完美融合到你的聊天舞台中。

## 3. 面板全局功能

### 3.1 历史记录 (History)
系统会自动记忆你生成过的所有图片和 3D 模型，即使刷新网页也不会丢失。

- **查看历史：** 点击右上角的 **“历史”** 按钮。
- **操作：** 在这里你可以重新预览、下载过去的资产。如果觉得记录太多，可以点击底部的 **“清空所有记录”**。

### 3.2 插件设置 (Settings) & 鉴权
为了保证你的 AI 接口额度安全，插件调用 API 时需要携带密钥（Token）。

- **配置 Token：** 点击右上角的 **“设置”** 按钮。
- **填写说明：**
  - **Token：** 填入你专属的访问密钥（必须与后端服务器 `.env` 中的 `PLUGIN_REQUIRED_TOKEN` 一致）。请使用随机生成的长令牌，不要把真实值提交到代码仓库。如果没有填对，生成时会提示 `Invalid token`。
  - **API Base URL：** 默认为空（自动使用当前域名）。本地开发时可填 `http://localhost:8787`。
  - **主题：** 支持切换 `Dark`（深色）和 `Light`（浅色）模式。

## 4. 常见问题 (FAQ)

**Q1：生成图片或 3D 时提示 `Invalid token` 怎么办？**
A：说明你的客户端未授权。请点击右上角“设置”，在 Token 一栏填入正确的密钥并保存。

**Q2：为什么 3D 模型一直在“加载中...”？**
A：请确保你的网络能够正常访问该模型链接；如果是本地上传的模型，由于浏览器安全限制，刷新后可能需要重新上传。

**Q3：我能把这个面板给别人用吗？**
A：完全可以！你可以查阅配套的《插件嵌入操作文档》，只需两行代码，别人就能把这个拥有完整功能的面板嵌入到他自己的网站上。

## 5. 配置与仓库安全

- 复制 `.streamlit/secrets.toml.example` 为 `.streamlit/secrets.toml`，再填写本机密钥。
- 服务端配置参考 `packages/plugin-server/.env.example`。
- 真实密钥、PEM、认证缓存、生成的 GLB/视频和构建产物不会提交到 Git。
- 生产环境请通过 HTTPS 同源反向代理暴露插件 API；`PLUGIN_BASE_URL` 与 `VITE_API_BASE_URL` 均可覆盖默认地址。
- 大型示例 GLB 和视频作为部署资产单独管理，仓库仅保存源码与配置模板。
